## 🎲 How to Play

### **Practice Mode** (Best for Learning!)
1. Click the green **"Practice Mode"** button
2. Choose a category (or "All Topics")
3. Answer questions at your own pace
4. Read the explanations to learn
5. No time limits, no pressure!

### **Test Mode** (Exam Simulation)
1. Click the orange **"Test Mode"** button
2. Get 25 random questions
3. You have 25 minutes (timer shows at top)
4. Need 72% to pass (18 out of 25)
5. See if you're ready for the real test!

### **Survival Mode** (Challenge!)
1. Click the yellow **"Survival Mode"** button
2. Start with 3 lives (hearts ❤️)
3. One wrong answer = lose a life
4. How long can you survive?
5. Beat your high score!

## 🆘 Troubleshooting

### **"The file won't open"**
- Right-click `game.html`
- Choose "Open with"
- Select your web browser (Chrome, Firefox, Safari, or Edge)

### **"It's not colorful, looks plain"**
- Make sure you opened `game.html` (NOT `index.html`)
- Try refreshing the page (press F5)
- Try a different browser

### **"Questions aren't loading"**
- Make sure you're opening `game.html`
- The new version has all questions built-in!
- If you see "Loading question..." stuck, refresh the page

### **"My progress isn't saving"**
- Don't use private/incognito mode
- Make sure cookies are enabled
- Use the same browser each time
